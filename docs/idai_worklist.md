## How to save one report (~15 seconds each)

1. Open the link.
2. If the page has a **"Download report"** PDF button → save the PDF into the folder. *(preferred:
   PDFs extract most cleanly and always carry the title + "as of" date)*
3. Otherwise → **Ctrl+S → "Webpage, HTML only"** into the same folder. *(HTML saves also carry the
   canonical URL, so nothing needs filling in by hand)*
4. Any filename is fine — the scanner reads the metadata from the file's contents.

If a save yields almost no text (you caught the bot-challenge page instead of the report), `--scan`
skips it with a warning and tells you which file to re-save.

## Why this is not automated

`reliefweb.int` answers every scripted client — `curl`, `httpx`, RSS feeds, and this project's
tooling alike — with an empty **HTTP 202** bot challenge, and the API needs the **pre-approved
appname** we are still waiting on. Defeating the challenge with a headless browser would be
circumventing an anti-bot measure, which CLAUDE.md rule 8 and PLAN §2a rule out. So the *fetching*
is manual; all the *bookkeeping* is automated. Once the appname is approved,
`python -m src.collect_reliefweb` replaces this entire page and re-collects the same reports with
citation-grade metadata.
